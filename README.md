# Портфолио Эльнура Агабалаева

Статический сайт: https://elnuremish.github.io/portfolio/

Чистые HTML, CSS и JavaScript без React, Framer runtime, npm и сборщика. Все страницы доступны без загрузки JavaScript. Плееры и автоматическое воспроизведение используют JavaScript; без него остаются прямые ссылки на видео.

## Редактирование

- `content/portfolio.json` — тексты, карточки и порядок материалов.
- `content/images.json` — каталог подготовленных изображений.
- `site.css` — общий адаптивный дизайн.
- `site.js` — отложенная подготовка видео и управление воспроизведением.
- `scripts/build.py` — генерация пяти HTML-страниц из контента.

После изменения контента или CSS/JS выполните в папке проекта:

```sh
python3 scripts/build.py
python3 -m http.server 8000
```

Откройте http://localhost:8000. Сайт можно запустить и без пересборки: готовые HTML включены в репозиторий. Python 3.9 или новее нужен только для пересборки.

## Загрузка медиа

Для каждого изображения сохранён исходный файл без повторного сжатия. Его разрешение доступно в `srcset`, включая версии 3200 px там, где это позволяет оригинал. Уменьшенные WebP подготовлены с качеством 95 в размерах 640, 1280, 1920 и 2560 px, без увеличения небольших исходников. Браузер выбирает размер под экран и его плотность пикселей. Ниже первого экрана действует `loading="lazy"`. На главной используется одна адаптивная обложка для всех устройств.

Изображения, контейнеры и видео имеют заданные пропорции, чтобы страница не сдвигалась при загрузке. Мобильная карточка растёт вместе с шириной экрана. На телефоне профиль становится компактной шапкой; на планшете плавно уменьшается; на компьютере остаётся поверх фотографий.

Видео Kinescope загружаются только вблизи видимой области. Используется официальный API и адаптивный поток Kinescope. Воспроизведение включается при появлении на экране, останавливается за пределами экрана и при скрытой вкладке. При экономии трафика или медленном соединении подготовка плеера откладывается до нажатия. При уменьшении движения автозапуск отключается.

Локальный MP4 имеет версии 720 и 1080, лёгкую обложку и подготовку перед появлением в кадре. Обе версии H.264, без звука: исходная анимация использовалась как немой цикл. Автозапуск — только в видимой области. Кнопка позволяет остановить анимацию вручную. MP4 оптимизированы для начала воспроизведения до полной загрузки (fast start).

Шрифты Inter (кириллица и латиница, 500 и 700) загружаются локально и переиспользуются на всех страницах. Остальные неиспользуемые шрифты удалены.

## Публикация

GitHub Pages: Settings → Pages → Source → GitHub Actions.
Публикацией управляет `.github/workflows/pages.yml`. После изменений в `main` он пересобирает страницы из `content/`, собирает готовый сайт в `_site/` и публикует его. В опубликованную папку входят только HTML, стили, JavaScript, иконки и медиафайлы. Все ссылки поддерживают папку `/portfolio/`.

Изменения во Framer не синхронизируются с этой самостоятельной копией. Материалы портфолио принадлежат их правообладателям.

Для подготовки изображений используйте `python3 scripts/prepare_images.py` (нужен Pillow). Исходники указаны в поле `source` файла `content/images.json`. Обычная сборка и публикация сайта не требуют Pillow.
