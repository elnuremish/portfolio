# Портфолио Эльнура Агабалаева

Самостоятельная статическая версия https://elnuremish.framer.website, перенесённая 3 ноября 2026 года. Сохранены опубликованная разметка и CSS для точного воспроизведения оформления. Framer JavaScript, аналитика и редактор не используются.

## Страницы
- `index.html` — главная и профиль поверх проектов.
- `scherdakov.html` — С Чердаков (адрес упрощён до латиницы).
- `adat.html` — ADAT.
- `nebesnaya.html` — Небесная канцелярия.
- `other.html` — Прочее.

Изображения, шрифты и MP4 находятся в `assets/`. Ролики Kinescope остаются внешними встроенными плеерами и требуют интернета. HTML и CSS экспортированы из опубликованного результата, это не исходные React-компоненты проекта Framer. Сгенерированные имена классов сохранены ради точности.

## Запуск на Mac
1. Открыть Терминал в папке проекта.
2. Выполнить `python3 -m http.server 8000`.
3. Открыть http://localhost:8000.

Установка Node.js или сборка не нужны.

## Как редактировать
Тексты и ссылки: соответствующий HTML. Оформление: CSS с тем же именем. Общие дополнения: `site.css`. Видео: `site.js`. Контент карточек главной продублирован в HTML для разных экранов — менять оба вхождения.

Сохранены брейкпоинты Framer: Desktop от 1200 px, Tablet 810–1199 px, Phone до 809 px. Пропорции мобильных карточек взяты из опубликованного сайта.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
Сайт: https://elnuremish.github.io/portfolio/
После изменения файлов в main сайт обновляется автоматически. Все ссылки и файлы относительные, поэтому папка /portfolio/ поддерживается.

Публикация в Framer больше не обновляет эту копию автоматически. Дальнейшие изменения нужно вносить в файлы репозитория.
