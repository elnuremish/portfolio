# Портфолио Эльнура Агабалаева

Статический сайт: https://elnuremish.github.io/portfolio/

Чистые HTML, CSS и JavaScript без React, Framer runtime, npm и сборщика. Все страницы доступны без загрузки JavaScript. Плееры и автоматическое воспроизведение используют JavaScript; без него остаются прямые ссылки на видео.

## Редактирование

- `content/portfolio.json` — тексты, карточки и порядок материалов.
- `content/en.json` — английские тексты; медиа и порядок берутся из основной версии.
- `content/images.json` — каталог подготовленных изображений.
- `site.css` — общий адаптивный дизайн.
- `site.js` — отложенная подготовка видео и управление воспроизведением.
- `scripts/build.py` — генерация русских и английских HTML-страниц из контента.

После изменения контента или CSS/JS выполните в папке проекта:

```sh
python3 scripts/build.py
python3 -m http.server 8000
```

Откройте http://localhost:8000. Сайт можно запустить и без пересборки: готовые HTML включены в репозиторий. Python 3.9 или новее нужен только для пересборки.

## Профиль при прокрутке

При входе показана полная карточка профиля. После прокрутки вниз она плавно сворачивается в строку контактов. На телефонах полная карточка раскрывается только при возвращении в самый верх страницы; на компьютере — при прокрутке вверх. Порог смены направления — 28 px; в начале страницы профиль всегда открыт. Обработчик прокрутки пассивный, обновления выполняются через requestAnimationFrame; размеры измеряются только при инициализации, изменении окна и загрузке шрифтов. На телефоне место исходной карточки сохраняется, чтобы лента не прыгала. Скрытые контакты исключены из навигации клавиатурой. При prefers-reduced-motion переходы отключены; без JavaScript остаётся исходный профиль.

## Загрузка медиа

Для каждого изображения сохранён исходный файл без повторного сжатия. На компьютерах главная страница использует WebP с качеством 95 и исходные JPEG. На телефонах доступны отдельные AVIF/WebP шириной 480, 800 и 1200 px. Внутри кейсов используются адаптивные AVIF с качеством 75 и цветом 4:4:4; запасной вариант — WebP с качеством 90 или прежний файл, если он меньше. Все варианты создаются прямо из оригиналов в размерах 640, 1280, 1920, 2560 px и полном исходном разрешении, без увеличения небольших изображений. Полное разрешение остаётся доступно в `srcset`. В `content/images.json` поля `case_avif` и `case_files` относятся только к лонгридам; `files` сохраняет изображения главной. Браузер выбирает формат и размер под экран и его плотность пикселей. Ниже первого экрана действует `loading="lazy"`. На компьютере следующие изображения кейсов запрашиваются заранее, в пределах 2400 px от экрана.

Изображения, контейнеры и видео имеют заданные пропорции, чтобы страница не сдвигалась при загрузке. Мобильная карточка растёт вместе с шириной экрана. На телефоне профиль становится компактной шапкой; на планшете плавно уменьшается; на компьютере остаётся поверх фотографий.

Видео используют локальные MP4 H.264 с fast start: 720p на телефонах и 1080p на компьютере. Постеры видны до первого кадра; маленькие встроенные превью появляются вместе с HTML. Подготовка видео начинается рядом с экраном, воспроизведение — в видимой области. Удалённые с экрана ролики прекращают скачивание, а при возвращении продолжают с сохранённой позиции. Скрытая вкладка также останавливает загрузку. Экономия трафика и уменьшение движения отключают автозапуск.

Стандартные элементы плеера отключены на всех устройствах. Единственная кнопка переключает звук; она создаётся только для видео с `hasAudio: true`. У ADAT звуковая дорожка удалена из обеих версий. Скрипты подготовки сохраняют выбранные оптимизированные и немые варианты. На главной код видео не создаёт наблюдатели и обработчики.

Шрифты Inter (кириллица и латиница, 500 и 700) загружаются локально и переиспользуются на всех страницах. Остальные неиспользуемые шрифты удалены.

## Публикация

GitHub Pages: Settings → Pages → Source → GitHub Actions.
Публикацией управляет `.github/workflows/pages.yml`. После изменений в `main` он пересобирает десять страниц из `content/`, собирает готовый сайт в `_site/` и публикует его. В опубликованную папку входят только HTML, стили, JavaScript, иконки и медиафайлы. Все ссылки поддерживают папку `/portfolio/`.

Изменения во Framer не синхронизируются с этой самостоятельной копией. Материалы портфолио принадлежат их правообладателям.

Для подготовки изображений используйте `python3 scripts/prepare_images.py` (нужен Pillow с поддержкой WebP и AVIF, например Pillow 12.3). Обложка «Прочее» использует отдельный оптимизированный набор AVIF/WebP. Для пересоздания одного набора используйте `python3 scripts/prepare_images.py --image other-cover-shirt`. Для обработки только кейсов используйте `python3 scripts/prepare_images.py --cases-only`, затем `python3 scripts/build.py`. Исходники указаны в поле `source` файла `content/images.json`. Обычная сборка и публикация сайта не требуют Pillow.

## Проверка

`node tests/media.mjs` проверяет автозапуск, паузу и возобновление, прекращение лишних загрузок, звук и запасной формат изображений. `python3 scripts/build.py` пересобирает страницы без зависимостей.

## Языки

Переключатель RU / EN — обычные ссылки внизу справа на всех страницах. Русские адреса сохранены; английские страницы имеют суффикс `-en.html`. Смена языка открывает тот же проект, ссылки внутри кейсов сохраняют язык. Перевод выполняется при сборке из `content/en.json`, без запросов к сторонним сервисам и библиотек в браузере. Изображения и видео общие для обеих версий; надписи внутри самих работ остаются частью оригинальных макетов.

`python3 tests/pages.py` проверяет полноту перевода, ссылки между языками и одинаковые настройки медиа.
